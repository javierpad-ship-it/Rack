# Marca Rack One

Colocá acá los archivos del logo, con estos nombres exactos:

- `rack-one-logo.png` — logo horizontal (monograma 1E + "Rack One"). Se usa en el login y la sidebar.
- `rack-one-icon.png` — ícono cuadrado (solo el 1E). Se usa como favicon.

Si falta `rack-one-logo.png`, la UI cae a un lockup tipográfico (glifo 1E + texto),
así nada queda roto. Ver `web/src/components/BrandLogo.tsx`.
